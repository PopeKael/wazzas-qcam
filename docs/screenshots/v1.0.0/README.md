# Version 1.0.0 screenshots

These screenshots were captured from the Android 15 Pixel 8 emulator running the version 1.0.0 debug build. The UI images use the emulator's simulated camera scene; physical camera and microphone behavior were checked separately on an OPPO Reno15 Pro 5G running Android 16.

- `splash-portrait.png` and `splash-landscape.png` capture the corresponding orientation-specific branded startup screens.
- `portrait-ui.png` and `landscape-ui.png` show the app after startup.
