# Release notes

## 1.0.0 — 2026-10-27

First public GitHub release of Wazza's QCam.

- One-screen teleprompter and CameraX recorder with portrait and landscape layouts.
- Local script library with clipboard paste, protected drafts, save/update, and reopen.
- Device-reported camera quality choices, camera switching, in-app brightness control, and recording timer.
- Rolling microphone graph based on CameraX recording statistics.
- MediaStore recordings in `Movies/WazzaCueCam` and Open Video handoff to the installed player.
- Orientation-selected branded splash screens and optional browser-based project support links.
- No in-app payments, advertising, analytics, account, cloud service, or Internet permission.

See the README for tested hardware and compatibility limits. Device-supported recording sizes can differ, particularly between front and rear cameras.
